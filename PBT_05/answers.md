# Phần A: Kiến thức lý thuyết

## 1. Responsive Web Design (RWD) là gì? Tại sao nó quan trọng?
Responsive Web Design (RWD) là phương pháp thiết kế web giúp trang web có thể tự động thay đổi giao diện, kích thước hình ảnh và bố cục để hiển thị tối ưu trên mọi loại thiết bị (máy tính, máy tính bảng, điện thoại).
Nó quan trọng vì:
- Cải thiện trải nghiệm người dùng (UX).
- Tiết kiệm chi phí bảo trì (chỉ dùng một URL duy nhất).
- Tốt cho SEO (Google ưu tiên các trang web thân thiện với di động).

## 2. Phân biệt Mobile First và Desktop First
- **Mobile First**: Thiết kế cho màn hình nhỏ nhất trước, sau đó dùng Media Queries để thêm các tính năng cho màn hình lớn hơn. Thường dùng `min-width`.
- **Desktop First**: Thiết kế cho màn hình lớn nhất trước, sau đó dùng Media Queries để ẩn hoặc thu nhỏ các thành phần cho màn hình nhỏ hơn. Thường dùng `max-width`.

## 3. CSS Transitions vs CSS Animations
- **Transitions**: Điều khiển sự thay đổi từ trạng thái này sang trạng thái khác (ví dụ: thay đổi màu khi hover). Cần có một sự kiện kích hoạt (trigger).
- **Animations**: Phức tạp hơn, có thể chạy tự động mà không cần sự kiện kích hoạt. Sử dụng `@keyframes` để định nghĩa nhiều bước chuyển động.
